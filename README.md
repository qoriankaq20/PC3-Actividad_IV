# PC3 - Actividad IV

Ejercicios de la práctica de campo 3, desarrollados en Python por el grupo 7.

## Contenido

- `1_voraces.py`: cambio de moneda y Dijkstra
- `2_recursivos.py`: suma de dígitos y conteo de ocurrencias
- `3_divide_venceras.py`: máximo y mínimo en una lista
- `4_backtracking.py`: strings de largo 3 con "a", "b" y "c"

## Ejecución

Cada archivo se ejecuta por separado con Python.
